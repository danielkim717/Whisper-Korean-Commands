# 데이터 준비

녹음 파일은 포함하지 않습니다. 이용 권한이 있는 WAV 음성을 준비하고 같은 화자가 Train과 Test에 겹치지 않게 분리하세요.

```text
data/
├── README.md
├── Train Dataset/
│   ├── 1-1_speaker01_take01.wav
│   └── ...
└── Test Dataset/
    ├── 1-1_speaker08_take01.wav
    └── ...
```

로더는 폴더 바로 아래 WAV만 읽으며 첫 밑줄 앞의 문자열을 명령어 코드로 해석합니다. 알 수 없는 코드는 건너뛰므로 로드 개수를 확인하세요. 학습에는 11개 명령어가 모두 필요합니다.

16 kHz 단일 채널로 읽어 앞 3초를 사용하고 짧으면 0으로 채웁니다. 기본 학습 경로는 무음 제거를 하지 않습니다. 파일명에는 이름·학번 대신 익명 화자 식별자를 쓸 수 있습니다. 음성과 생성 가중치는 Git에서 제외됩니다.

발표는 8명×5회×11명령어와 화자별 Train 7명/Test 1명을 설명하지만 저장 로그는 Train 99/Test 55입니다. 원본 음성이 없어 실제 화자 분할은 독립 확인하지 못했습니다.
