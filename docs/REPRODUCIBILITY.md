# 실행 및 검증 범위

## 실행

`requirements.txt` 설치와 FFmpeg가 필요합니다. 원본은 Colab 기반이며 출력에 Python 3.12 경로가 남아 있지만 패키지 버전·GPU는 고정 기록되어 있지 않습니다. 현재 의존성 목록은 설치 안내이며 원래 환경의 lock 파일이 아닙니다. 처음 실행하면 Whisper 가중치를 내려받고 전체 인코더를 학습하므로 자원 요구량은 실행 환경에서 확인해야 합니다.

1. [데이터 안내](../data/README.md)에 따라 WAV를 준비한다.
2. [정리 노트북](../notebooks/whisper_commands.ipynb)을 연다.
3. `BASE_PATH` 또는 `KWS_DATA_DIR`를 설정한다. Colab에서는 저장소 전체를 준비하고 필요한 경우 본인이 Drive를 마운트한다.
4. 전처리→학습→분류 평가→프로토타입→거절 평가→저장을 순서대로 실행한다.
5. `outputs/`에서 학습 이력, 거절 평가 JSON, 가중치를 확인한다.

## 정리본 변경 범위

- 보관 노트북은 원본 셀 소스를 보존하고 실행 출력·번호·Colab 메타데이터를 제거했다.
- `src/data.py`, `src/model.py`, `src/unknown.py`의 핵심 함수·클래스는 원본에서 추출했다. 수치 연산과 모델 구조는 바꾸지 않았다.
- 정리 노트북은 `traced`·`wrapped` 등의 숨은 상태 의존성을 없애고 변수를 명시적으로 구성했다.
- 학습·거리 기준·거절에 동일한 RawAudio 전처리를 사용한다. 원본 후반의 무음 제거+별도 Mel 경로와 다르다.
- 기준은 현재 학습 거리 p99로 계산한다. 원본 export의 고정값 0.125와 결과가 달라질 수 있다.
- `num_workers=0`을 사용해 Windows/Jupyter 프로세스 생성 문제를 줄였다.
- 모바일 export는 선택 실행이며, 미정의 `eval_dataset`·`unique_labels` 기반 MFCC 후반 실험은 보관본에만 남겼다.

정리본의 결과는 실제 데이터로 새로 실행해 기록해야 합니다. 원래 결과를 재현했다고 주장하지 않습니다. 원본에는 seed 고정과 화자별 파일 명세도 없습니다.

## 확인할 기술적 사항

**전처리 차이:** 사용자 모델은 명시적 reflect padding 뒤 기본 `center=True`의 STFT를 호출하고 300 프레임으로 자릅니다. [공식 Whisper 오디오 코드](https://github.com/openai/whisper/blob/main/whisper/audio.py)와 동일한 프레임 처리 경로가 아닙니다. 변경 시 기존 가중치와의 호환성·재학습 필요성을 확인해야 합니다.

**배치 의존성:** 로그 Mel의 최대를 배치 전체에서 계산해 같은 파일도 함께 묶인 다른 파일의 영향을 받을 수 있습니다. 학습 batch 16과 모바일 batch 1의 차이를 확인해야 합니다. 원본 결과를 보존하기 위해 수식을 임의 수정하지 않았습니다.

**중복 연산:** Unknown 래퍼는 분류와 거리를 위해 인코더를 두 번 실행합니다. 배포용 최적화 과제지만 추출 구현은 원본을 보존했습니다.

**거리 기준:** 자기 자신을 포함한 학습 중심과의 거리 백분위수는 독립 검증 성능이 아니며 p99는 정답 또는 탐지 확률 99%가 아닙니다.

**모바일:** trace 입력은 1×48000이며 저장 파일 로그는 1,033,942,969바이트입니다. Lite 방식의 런타임 지원, STFT 연산, export 전후 일치, 기기 메모리와 지연시간을 별도 확인해야 합니다.

**원본 상태:** 함수 내부에서 생성한 `traced`·`wrapped`를 외부 셀에서 참조하고 CPU 모델과 CUDA 입력이 섞일 가능성이 있습니다. MFCC의 미정의 변수도 있어 저장 출력이 전체 순차 실행의 증거는 아닙니다.

## 이번 확인 범위

노트북 JSON과 코드 구문, 원본 대비 핵심 AST 일치, 11개 라벨 순서, 결과 집계, 문서 링크, 인증정보 패턴을 점검했습니다. 결과는 [PUBLICATION_CHECKS.md](PUBLICATION_CHECKS.md)에 기록합니다. 음성·가중치가 없고 학습 런타임을 실행하지 않아 전체 학습·추론·모바일 동작은 검증하지 않았습니다.
