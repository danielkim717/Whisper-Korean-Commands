# 결과와 근거

수치는 원본 노트북의 저장 출력과 발표자료에서 정리했습니다. 새로 재학습하거나 앱을 실행한 결과가 아닙니다.

cell 10은 Train 99/Test 55를, cell 13은 마지막 55개 모두 정답(명령어당 5개)을 기록합니다. 이는 등록된 명령어의 소규모 평가입니다. 원본 음성이 없어 화자 중복·분할 이력을 확인하지 못했습니다. 매 epoch Test를 모니터링하므로 설정 선택까지 포함한 독립 최종 검증으로 확대 해석하지 않습니다.

## 거리와 Unknown

cell 20은 학습 임베딩 99×768, Test 55×768, 중심 11×768을 기록합니다. 학습 `d_true` 백분위수는 p90=0.0667, p95=0.0794, p97=0.0949, p99=0.1247입니다. cell 14 export는 0.125를 사용합니다.

cell 19의 저장 보고서를 클래스별로 집계하면 46개 정답, 9개 Unknown 거절로 약 83.6%입니다. Unknown 실제 정답은 0개이므로 탐지율·정밀도·AUROC는 평가할 수 없습니다. 함수 내부 변수, CPU 이동, 다른 전처리 경로가 섞여 있어 같은 실행의 특정 임계값 효과라고 확정하지 않습니다.

## 자료별 차이

| 항목 | 발표자료 | 노트북 |
|---|---|---|
| 자료 개요 | 8명×5회×11명령어, 약 440개 | 로그상 Train 99/Test 55 |
| 화자 분할 | Train 7명/Test 1명 | 폴더 로드 코드만 있고 화자 명세 없음 |
| Epoch | 10 | 코드·로그 모두 8 |
| 알려진 명령어 | 그림상 55/55 정답 | 55/55 정답 |
| Unknown 적용 | 그림상 52개 정답, 3개 거절 | 보고서상 46개 정답, 9개 거절 |
| 백분위수 출처 | 본문에 Test라고 기재 | 코드·출력은 Train `d_true` |
| 분류기 | ‘선형 분류기’ | 두 선형층 사이 ReLU·Dropout |

발표의 Unknown 그림에서는 불 꺼·뒤로 가·전화 받아에서 각각 1개를 거절합니다. 서로 다른 결과를 하나의 실험으로 합치지 않았습니다. 발표의 Wav2Vec2 정확도 30–40%는 대응 코드·모델 식별자·공통 평가 조건이 없어 검증된 모델 비교 표에서 제외했습니다. 한국어 학습 여부만으로 성능 차이의 원인을 단정하지 않습니다.
